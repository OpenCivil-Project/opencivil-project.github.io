# Website media

Place your final files here, then set their URLs in `src/data/media.ts`:

| Slot | Suggested filename | Recommended format |
| --- | --- | --- |
| Model / implementation image | implementation-model.png | 1920 × 1080 PNG or WebP, 16:9 |
| Walkthrough video | implementation-walkthrough.mp4 | 1920 × 1080 MP4 (H.264), 16:9 |

Use URLs beginning with `/media/`. An empty URL displays the placeholder. Images use contain sizing, so diagrams will not be cropped. Videos have native controls and do not autoplay. Existing demonstrations remain available on the Implementation page.
